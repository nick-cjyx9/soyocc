# SoyoCC

Nick 学习编译原理的产物，基本是 [chibicc](https://github.com/rui314/chibicc) 的翻版。

## 编译&使用

soyocc 使用 [nob.h](https://github.com/tsoding/nob.h) 作为构建系统

```bash
cc -o nob nob.c && ./nob
```
